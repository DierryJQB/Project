# Project
# 🧠 ChronoBrain - Bio-Monitoring Station

 

Plataforma web interactiva en 3D que monitorea en tiempo real la neuroquímica, los ritmos circadianos y el estado funcional de las diferentes regiones cerebrales según la hora del día del usuario.

 

## 🚀 Características Principales

 

- **Visualizador 3D Interactivo:** Modelo tridimensional del cerebro con manipulación en todos los ejes e iluminación reactiva por zonas (Three.js).

- **Reloj Circadiano Dinámico:** Sincronización automática con el huso horario local para mostrar la hormona dominante y el nivel de rendimiento cognitivo.

- **Modo Estado de Sueño / Vigor:** Adaptación de datos según si el usuario está despierto o respetando el ciclo de descanso.

- **Arquitectura Segura:** Backend en Python que protege la información médica y previene revelaciones no autorizadas de datos.

 

## 🛠️ Tecnologías Utilizadas

 

- **Frontend:** HTML5, CSS3 (Custom Properties & Glassmorphism), JavaScript (ES6+), Three.js (3D WebGL Rendering).

- **Backend / DB:** Python (Flask/FastAPI), SQLite.

- **Control de Versiones:** Git & GitHub.
